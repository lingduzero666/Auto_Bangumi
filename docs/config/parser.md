# 解析器设置

AB 的解析器用于分析 RSS 条目标题，并生成番剧、季度、集数、字幕组等结构化信息。

::: tip
从 v3.1 开始，单个 RSS 的来源解析器在添加或编辑 RSS 时设置。这里的 **解析设置** 控制全局开关、标题解析器、元数据语言、默认偏好与过滤规则。
:::

## WebUI 配置

- **启用**：是否启用 RSS 解析器。关闭后不会自动解析新 RSS 条目。
- **标题解析器**：`经典解析器（稳定）` 保持原有行为；`通用解析器（Preview）` 支持剧集范围、OVA、剧场版与混合合集。两种模式不会自动互相回退。
- **元数据语言**：查询 TMDB 时使用的语言，决定番剧官方标题与海报用哪种语言，目前支持 `zh`、`jp` 和 `en`。**与字幕语言无关。**
- **排除**：全局过滤规则。可以输入普通字符串或正则表达式，匹配到的 RSS 条目会在解析阶段被过滤。
- **默认偏好字幕组 / 默认偏好分辨率 / 默认偏好字幕语言 / 默认偏好字幕压制**：新番剧首次入库时写入该番剧的偏好起点，留空即不设默认。详见下方 [默认发布偏好](#默认发布偏好)。

## `config.json` 配置选项

配置节：`rss_parser`

| 参数 | 说明 | 类型 | WebUI 选项 | 默认值 |
| --- | --- | --- | --- | --- |
| `enable` | 启用 RSS 解析器 | 布尔值 | 启用 | `true` |
| `engine` | 标题解析器：`classic` 或 `tokenizer` | 字符串 | 标题解析器 | `classic` |
| `filter` | 全局过滤规则 | 字符串数组 | 排除 | `["720", "\\d+-\\d+"]` |
| `language` | TMDB 元数据语言 | 字符串 | 元数据语言 | `zh` |
| `default_preferred_group` | 新番剧的默认偏好字幕组 | 字符串 | 默认偏好字幕组 | `""` |
| `default_preferred_resolution` | 新番剧的默认偏好分辨率 | 字符串 | 默认偏好分辨率 | `""` |
| `default_preferred_subtitle_language` | 新番剧的默认偏好字幕语言 | 字符串 | 默认偏好字幕语言 | `""` |
| `default_preferred_subtitle_style` | 新番剧的默认偏好字幕压制 | 字符串 | 默认偏好字幕压制 | `""` |

## 默认发布偏好

同一个字幕组常常把同一集发布成多个版本（例如「简繁内封」「繁体内嵌」「简体内嵌」），字幕组与分辨率完全相同。这类重复发布会被全部下载，重命名后目标文件名一致而互相冲突。

四项发布偏好用来在这种情况下挑出要保留的那一个：RSS 刷新时，同一集的多个候选按命中的偏好项数打分，只保留得分最高的一个，其余跳过。四项等权，填了几项就用几项分高下；一项都不填时不做任何去重，与旧行为一致。

### 取值

`default_preferred_subtitle_language` 与 `default_preferred_subtitle_style` 是规范化枚举，不接受自由文本：

| 字幕语言 | 含义 | 可识别的写法（示例） |
| --- | --- | --- |
| `chs` | 简体 | 简体、简中、简日双语、CHS、GB、JPSC |
| `cht` | 繁体 | 繁体、繁中、繁日、CHT、Big5、JPTC |
| `chs_cht` | 简繁 | 简繁、繁简、CHS&CHT |
| `jpn` | 日语 | 日语、日文、JPN |
| `eng` | 英语 | 英语、英文、ENG、VOSTFR |

| 字幕压制 | 含义 | 可识别的写法（示例） |
| --- | --- | --- |
| `embedded` | 内嵌（硬字幕） | 内嵌、硬字幕 |
| `muxed` | 内封（软字幕） | 内封 |
| `external` | 外挂 | 外挂、外置 |

标题里认不出对应标记时该维度不计分，但不会因此漏下整集。

### 作用范围

::: warning
这四项是**新番剧入库时的默认值**，只在番剧首次被发现时写入该番剧，之后修改这里不会影响任何已有番剧。
:::

已入库的番剧在「番剧规则」里逐个调整对应的偏好字段。想让某部老番也按新默认走，直接编辑该番剧的规则即可。
