# 解析器设置

AB 的解析器用于分析 RSS 条目标题，并生成番剧、季度、集数、字幕组等结构化信息。

::: tip
从 v3.1 开始，单个 RSS 的来源解析器在添加或编辑 RSS 时设置。这里的 **解析设置** 控制全局开关、标题解析器、语言与过滤规则。
:::

## WebUI 配置

- **启用**：是否启用 RSS 解析器。关闭后不会自动解析新 RSS 条目。
- **标题解析器**：`经典解析器（稳定）` 保持原有行为；`通用解析器（Preview）` 支持剧集范围、OVA、剧场版与混合合集。两种模式不会自动互相回退。
- **语言**：解析器偏好的标题语言，目前支持 `zh`、`jp` 和 `en`。
- **放送星期数据源**：日历的放送星期先查哪个来源。`优先 Bangumi.tv` 保持既有行为；`优先解析器` 按每条订阅自己的解析类型取数——`mikan` 与 `mix` 读番剧主页上的「放送日期」，`tmdb` 由播出日期推算，其余类型没有解析器来源。无论选哪个，首选来源匹配不到的番剧都会用另一个来源兜底。国内访问 bgm.tv 受限时建议选解析器优先。
- **排除**：全局过滤规则。可以输入普通字符串或正则表达式，匹配到的 RSS 条目会在解析阶段被过滤。

## `config.json` 配置选项

配置节：`rss_parser`

| 参数 | 说明 | 类型 | WebUI 选项 | 默认值 |
| --- | --- | --- | --- | --- |
| `enable` | 启用 RSS 解析器 | 布尔值 | 启用 | `true` |
| `engine` | 标题解析器：`classic` 或 `tokenizer` | 字符串 | 标题解析器 | `classic` |
| `filter` | 全局过滤规则 | 字符串数组 | 排除 | `["720", "\\d+-\\d+"]` |
| `language` | 解析语言 | 字符串 | 语言 | `zh` |
| `weekday_source` | 放送星期数据源：`bgm` 或 `parser` | 字符串 | 放送星期数据源 | `bgm` |
