# カレンダービュー

v3.2以降、ABには購読しているアニメを放送日ごとに整理して表示するカレンダービューが含まれています。

![Calendar](/image/feature/calendar.png)

## 機能

### 週間スケジュール

カレンダーは、放送曜日（月曜日から日曜日）ごとに整理されたアニメを表示し、放送スケジュールデータのないアニメ用の「不明」列もあります。

### 放送スケジュールの取得元

ABには放送曜日の取得元が2つあり、**設定 → 解析設定 → 放送曜日の取得元**でどちらを先に問い合わせるか選べます。

- **Bangumi.tv**（既定）：Bangumi.tvの放送スケジュールにタイトルで照合します。
- **パーサー**：各購読のパーサー種別に従います。`mikan` と `mix` はMikanの番組ページに明記された「放送日期」を読み、`tmdb` はTMDBの放送日から算出します。その他の種別にパーサー取得元はありません。

どちらを選んでも、優先した取得元で解決できなかった作品にはもう一方がフォールバックとして使われるため、いずれの設定でも「不明」列は減ります。bgm.tvに接続できない環境ではパーサー優先を推奨します。

手動で指定した放送日（カレンダー上でのドラッグ）は常に優先され、更新で上書きされません。

**スケジュールを更新**ボタンをクリックして、放送データを更新します。パーサー優先の場合は作品ごとに取得するため、Bangumi.tvの1回のリクエストより時間がかかります。

### グループ表示

v3.2以降、複数のダウンロードルールを持つアニメはグループ化されます：

- 複数の字幕グループルールがあっても、同じアニメは1回だけ表示されます
- グループ化されたアニメをクリックすると、利用可能なすべてのルールが表示されます
- 特定のルールを選択して編集

これにより、すべてのルールへのアクセスを提供しながら、カレンダーをすっきり保ちます。

## ナビゲーション

カレンダー内の任意のアニメポスターをクリックして：
- アニメの詳細を表示
- ダウンロードルールを編集
- アーカイブ/無効化オプションにアクセス

## ヒント

::: tip
アニメが「不明」列に表示される場合、どちらの取得元でも放送曜日を解決できなかったことを意味します。「放送曜日の取得元」をもう一方に切り替えて再度更新するか、正しい曜日にドラッグして手動で指定してください。
:::
