# パーサー設定

パーサーはRSSタイトルから作品名、シーズン、話数、字幕組などを抽出します。

::: tip
v3.1以降、RSSごとのソースパーサーはRSS追加または編集時に設定します。このページではグローバルな有効化、タイトルパーサー、メタデータ言語、既定の優先設定、フィルターを設定します。
:::

## WebUI

- **有効化**：RSS解析を有効化します。
- **タイトルパーサー**：`Classic parser (Stable)` は従来の動作を維持します。`Universal parser (Preview)` は話数範囲、OVA、劇場版、混合集を解析します。両エンジンは自動的に相互フォールバックしません。
- **メタデータ言語**：TMDB 検索に使う言語で、作品の正式名称とポスターの言語を決めます。`zh`、`jp`、`en` をサポートします。**字幕の言語とは無関係です。**
- **除外**：グローバルフィルターです。文字列または正規表現を指定できます。
- **既定の優先字幕組 / 既定の優先解像度 / 既定の優先字幕言語 / 既定の優先字幕形式**：新規作品が初めて登録される際に書き込まれる優先設定の初期値です。空欄なら既定値を設定しません。詳細は [既定のリリース優先設定](#既定のリリース優先設定) を参照してください。

## `config.json`

セクション：`rss_parser`

| キー | 説明 | 型 | WebUI項目 | 既定値 |
| --- | --- | --- | --- | --- |
| `enable` | RSSパーサーを有効化 | 真偽値 | 有効化 | `true` |
| `engine` | タイトルパーサー：`classic` または `tokenizer` | 文字列 | タイトルパーサー | `classic` |
| `filter` | グローバル除外ルール | 文字列配列 | 除外 | `["720", "\\d+-\\d+"]` |
| `language` | TMDB メタデータ言語 | 文字列 | メタデータ言語 | `zh` |
| `default_preferred_group` | 新規作品の既定の優先字幕組 | 文字列 | 既定の優先字幕組 | `""` |
| `default_preferred_resolution` | 新規作品の既定の優先解像度 | 文字列 | 既定の優先解像度 | `""` |
| `default_preferred_subtitle_language` | 新規作品の既定の優先字幕言語 | 文字列 | 既定の優先字幕言語 | `""` |
| `default_preferred_subtitle_style` | 新規作品の既定の優先字幕形式 | 文字列 | 既定の優先字幕形式 | `""` |

## 既定のリリース優先設定

同じ字幕組が同一話を複数のバージョン（例：「簡繁内封」「繁体内嵌」「簡体内嵌」）で公開することがよくあります。字幕組も解像度も同一のため、これらはすべてダウンロードされ、リネーム後に同じファイル名となって衝突します。

4 つのリリース優先設定は、この場合にどれを残すかを決めます。RSS 更新時、同一話の候補は一致した優先項目の数で採点され、最高得点のものだけが残ります。4 項目は等しい重みを持ち、入力した項目数だけが判定に使われます。1 つも設定しなければ重複排除は行われず、従来の動作のままです。

### 設定値

`default_preferred_subtitle_language` と `default_preferred_subtitle_style` は正規化された列挙値で、自由入力は受け付けません。

| 字幕言語 | 意味 | 認識される表記（例） |
| --- | --- | --- |
| `chs` | 簡体字 | 简体、简中、简日双语、CHS、GB、JPSC |
| `cht` | 繁体字 | 繁体、繁中、繁日、CHT、Big5、JPTC |
| `chs_cht` | 簡繁併記 | 简繁、繁简、CHS&CHT |
| `jpn` | 日本語 | 日语、日文、JPN |
| `eng` | 英語 | 英语、英文、ENG、VOSTFR |

| 字幕形式 | 意味 | 認識される表記（例） |
| --- | --- | --- |
| `embedded` | 焼き込み（ハードサブ） | 内嵌、硬字幕 |
| `muxed` | 内封（ソフトサブ） | 内封 |
| `external` | 外部ファイル | 外挂、外置 |

タイトルに該当する表記が見つからない場合、その項目は加点されないだけで、話数が取りこぼされることはありません。

### 適用範囲

::: warning
この 4 項目は**新規作品の登録時に適用される既定値**です。作品が初めて登録された時点でのみ書き込まれ、後から変更しても既存の作品には一切影響しません。
:::

登録済みの作品は、各作品のルールで個別に調整してください。
